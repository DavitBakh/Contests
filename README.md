Комплексный фреймворк, библиотека классических алгоритмов, структур данных и набор сниппетов для **спортивного программирования** (Codeforces, AtCoder, LeetCode, ICPC, CodeChef, HackerRank).

Проект сконфигурирован под среду **Visual Studio 2022** (стандарт **C++20**) и содержит всё необходимое для быстрого старта, отладки и решения олимпиадных задач любой сложности.

## 📌 Основные возможности

- ⚡ **Оптимизированный шаблон решения (`Source.cpp`)**: быстрый ввод/вывод (`cin.tie / sync_with_stdio`), поддержка локального перенаправления ввода из файла `input.txt` через макрос `_LOCAL`.
- 🧩 **Структуры данных**:
  - **Segment Tree (`SegTree.h`)** — дерево отрезков с поддержкой точечного обновления и запросов суммы на подотрезке за $O(\log N)$.
  - **Trie (`Trie.hpp`)** — префиксное дерево с операциями вставки, поиска, проверки префикса и удаления.
  - **BigInt (`BigInt.hpp`)** — полноценная длинная арифметика целых чисел с поддержкой всех базовых операторов (`+`, `-`, `*`, `/`, `%`), знаков и потокового ввода/вывода.
  - **BigDecimal (`BigDecimal.hpp`)** — произвольная точность для чисел с плавающей точкой (длинная вещественная арифметика, возведение в степень).
  - **Modular Arithmetic (`Modular.cpp`)** — класс кольца вычетов по модулю с быстрым нахождением обратного элемента через расширенный алгоритм Евклида.
- 📐 **Библиотека алгоритмов (`Utils.hpp`)**:
  - **Графы**: поиск в глубину (DFS), поиск цикла в графе с восстановлением пути, поиск в ширину (BFS), алгоритм Дейкстры (кратчайшие пути за $O(E \log V)$), алгоритм Прима (минимальное остовное дерево за $O(E \log V)$).
  - **Строки**: Z-функция (`GetZF`) за линейное время $O(N)$.
  - **Динамическое программирование**: наибольшая общая подпоследовательность (LCS — Longest Common Subsequence).
  - **Теория чисел и математика**: решето Эратосфена, расширенный алгоритм Евклида (Extended GCD), бинарное возведение в степень по модулю (`binpow`).
  - **Разделение массивов**: `partition` (схема разделения Ломуто/Хоара для быстрых поисков порядка статистики).
- 📋 **Интеграция с буфером обмена Windows (`Utils.hpp`)**:
  - Функции `CopyToClipboard` и `GetFromClipboard` через Win32 API для моментальной вставки тестовых данных и копирования ответов.
- 🖱️ **Эмуляция ввода (`InputSimulator.hpp`)**:
  - Утилиты на базе `SendInput` для кликов мыши, нажатий клавиш и автоматической вставки (`Ctrl+V`), а также низкоуровневые хуки клавиатуры.
- 🧮 **Интеграция Primesieve**:
  - В проект встроен быстрый генератор простых чисел **[primesieve](https://github.com/kimwalisch/primesieve)** с поддержкой AVX-512, SSE2 и ARM SVE для задач, требующих сверхбыстрого просеивания простых чисел в огромных диапазонах.
- 🚀 **Поддержка `<bits/stdc++.h>` в MSVC (`Includes/bits/stdc++.h`)**:
  - Позволяет компилировать решения в Visual Studio без изменения заголовочных файлов, привычных для GCC/Clang.
- ⏱️ **Коллекция сниппетов Visual Studio (`Snippets/C++`)**:
  - 20 готовых `.snippet` файлов для мгновенной генерации кода во время контестов по горячим клавишам.

## ⌨️ Сниппеты Visual Studio (Snippets)

Сниппеты ускоряют написание шаблонного кода до считанных секунд.

| Шорткат | Название / Назначение | Описание |
| :--- | :--- | :--- |
| `fastIO` | Fast Input/Output | Отключает синхронизацию потоков (`sync_with_stdio(0); cin.tie(0); cout.tie(0);`) |
| `includeAll` | Standard Includes | Подключает все часто используемые библиотеки C++ STL |
| `forn` | Loop 0..n (int) | Цикл `for (int i = 0; i < n; ++i)` |
| `forl` | Loop 0..n (long long) | Цикл `for (long long i = 0; i < n; ++i)` |
| `Bfs` | Breadth-First Search | Шаблон обхода графа в ширину на очереди `std::queue` |
| `Dfs` | Depth-First Search | Рекурсивный обход графа в глубину |
| `DfsCycle` | Graph Cycle Detection | Поиск и восстановление цикла в ориентированном/неориентированном графе |
| `Djikstra` | Dijkstra Algorithm | Кратчайшие пути от вершины во взвешенном графе с `std::priority_queue` |
| `Prim` | Prim MST | Минимальное остовное дерево взвешенного графа |
| `GCD` | Extended Euclidean | Вычисление НОД и коэффициентов Безу $a \cdot x + b \cdot y = \gcd(a, b)$ |
| `BinPow` | Binary Exponentiation | Быстрое возведение $a^b \pmod m$ за $O(\log b)$ |
| `GetZ` | Z-Algorithm | Вычисление Z-массива строки за линейное время $O(N)$ |
| `LCS` | Longest Common Subseq | Динамическое программирование для поиска длины LCS за $O(N \cdot M)$ |
| `Partition` | Array Partition | Разбиение массива относительно опорного элемента |
| `cr` | Cin Read | `std::cin >> ...;` |
| `cw` | Cout Write | `std::cout << ... << ' ';` |
| `cwe` | Cout Write Endl | `std::cout << ... << '\n';` |
| `cast` | Static Cast | `static_cast<type>(val)` |
| `lamda` | Lambda Expression | Определение лямбда-функции `auto f = [&](...) { ... };` |
| `ul` | Type Alias | `unsigned long long` |

### Как подключить сниппеты в Visual Studio:
1. Откройте **Visual Studio 2022**.
2. В верхнем меню выберите **Инструменты (Tools)** $\rightarrow$ **Диспетчер фрагментов кода (Code Snippets Manager)** (или нажмите `Ctrl + K, Ctrl + B`).
3. В выпадающем списке языка выберите **C++**.
4. Нажмите кнопку **Добавить (Add)** и укажите папку `Snippets/C++` из этого репозитория (либо нажмите **Импорт** и выберите нужные файлы).
5. Теперь при наборе шортката (например, `fastIO` или `Djikstra`) и нажатии `Tab` код будет автоматически разворачиваться.

## 💻 Сборка и запуск

### Требования
- **ОС**: Windows 10 / 11 (x64 или x86)
- **Среда разработки**: Visual Studio 2022 (с установленным набором инструментов «Разработка классических приложений на C++»)
- **Стандарт C++**: C++20 (`/std:c++20`)
- **Toolset**: `v143`

### Запуск проекта
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/DavitBakh/Contests.git
   ```
2. Откройте решение `Contests.sln` в Visual Studio.
3. Выберите конфигурацию **Debug | x64** (или **Release | x64**).
4. Запишите входные данные задачи в файл `Contests/input.txt`.
5. Нажмите `F5` или `Ctrl + F5` для сборки и запуска.

При сборке в Debug автоматически активируется директива `_LOCAL`, которая перенаправляет ввод со стандартного потока на чтение из `input.txt`:
```cpp
#ifdef _LOCAL
    freopen("input.txt", "r", stdin);
#endif
```
При отправке решения в тестирующую систему (например, на Codeforces) макрос `_LOCAL` не определен, поэтому программа прозрачно читает данные из стандартного потока `stdin`.

## 📜 История развития проекта (Commits Log)

Проект активно развивался через добавление алгоритмов, структур данных и оптимизаций:

- **Начальная инициализация**: Настройка решения под Visual Studio, реализация длинной арифметики (`BigInt`, `BigDecimal`), модульной арифметики (`Modular.cpp`), `<bits/stdc++.h>` для MSVC и утилит эмуляции ввода `InputSimulator`.
- **Интеграция сниппетов**: Создание первой версии сниппетов ввода/вывода (`fastIO`, `forn`, `includeAll`, `cast`, `lamda`).
- **Расширение алгоритмической базы**:
  - Добавление Z-функции (`GetZF`) для быстрого сопоставления подстрок.
  - Реализация префиксного дерева (`Trie`).
  - Добавление алгоритма Дейкстры для поиска кратчайших путей и решета Эратосфена.
- **Подключение Primesieve**: Интеграция высокоскоростной библиотеки генерации простых чисел `primesieve` с поддержкой векторных процессорных инструкций.
- **Динамическое программирование и остовы**: Добавление алгоритма наибольшей общей подпоследовательности (LCS) и алгоритма Прима для минимальных остовных деревьев.
- **Сниппеты графов и теории чисел**: Добавлены сниппеты для BFS, DFS, поиска циклов, бинарного возведения в степень и расширенного алгоритма Евклида.
- **Дерево отрезков (`SegTree.h`)**: Реализация эффективного Segment Tree с поддержкой изменения элементов и быстрых запросов на отрезках.
